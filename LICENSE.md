## 1. DEFINICIONES

**1.1. "el Software"**

Todo el código fuente, programación, scripts y ficheros técnicos de este repositorio que no sean Contenido Publicado según se define en 1.2 — incluyendo, sin limitación:

- Scripts de compilación y generación automática (carpeta `build/`)
- Plantillas, código HTML, CSS, JavaScript y otros lenguajes de programación del sitio web (carpeta `site/`)
- Flujos de trabajo de automatización y archivos de configuración (`.github/workflows/`, `.gitignore`, ficheros de configuración, etc.)
- Documentación técnica (README.md, ficheros de especificación técnica, etc.)
- Herramientas de administración, mantenimiento y auditoría del catálogo
- Cualquier otro fichero o componente del repositorio destinado a generar, mantener, administrar, servir o gestionar el catálogo y el sitio web, exista o no una carpeta `dist/` u otra copia ya compilada o construida en el propio repositorio

El Software incluye trabajos derivados y modificaciones, realizadas por los Colaboradores, sobre el código fuente original.

**1.2. "el Contenido Publicado"**

El sitio web ya compilado y construido, tal y como se sirve públicamente en tiempo real desde el dominio oficial **biblioteca.fio.es** (y únicamente desde ese dominio u otros dominios oficiales de la Fundación debidamente identificados) — incluyendo:

- Páginas HTML generadas
- Textos, catálogos consultables, índices y bases de datos
- Imágenes, gráficos y ficheros multimedia propios del sitio (que no sean propiedad de terceros)
- Ficheros de datos, metadatos y estructuras de datos servidos desde ese dominio para su visualización, consulta y acceso público mediante navegador web

El Contenido Publicado **no incluye** el Software que lo genera, ni el código fuente de este repositorio, ni ningún fichero técnico de administración.

**1.3. "los Colaboradores"**

Las personas físicas voluntarias que han contribuido, contribuyen o mantendrán el Software de forma desinteresada y sin contraprestación económica inmediata a favor de la Fundación Infante de Orleans, incluyendo desarrolladores, diseñadores, redactores técnicos, correctores y otros profesionales que cedan sus contribuciones bajo los términos de esta licencia.

**1.4. "la Fundación"**

La Fundación Infante de Orleans (FIO), entidad sin ánimo de lucro inscrita en el Registro de Fundaciones del Ministerio de Derechos Sociales y Agenda 2030, con domicilio en Aeródromo de Cuatro Vientos, Madrid, como entidad titular, beneficiaria y responsable del Software y del Contenido Publicado.

**1.5. "Terceros"**

Cualquier persona física o jurídica que no sea la Fundación ni un Colaborador expresamente autorizado por la Junta Directiva.
