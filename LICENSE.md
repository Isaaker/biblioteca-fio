1. DEFINICIONES
-----------------------------------------------------------

1.1. "el Software": todo el código fuente de este repositorio que no
     sea Contenido Publicado según se define en 1.2 — incluyendo, sin
     limitación, los scripts de compilación (carpeta `build/`), las
     plantillas y código fuente del sitio (carpeta `site/`, HTML, CSS,
     JavaScript), los flujos de trabajo de automatización
     (`.github/workflows/`), documentación técnica, y cualquier otro
     fichero de este repositorio destinado a generar, mantener o
     administrar el catálogo y el sitio web, exista o no una carpeta
     `dist/` u otra copia ya construida en el propio repositorio.

1.2. "el Contenido Publicado": el sitio web ya construido, tal y como
     se sirve públicamente y en tiempo real desde el dominio
     **biblioteca.fio.es** (y únicamente desde ese dominio) —
     páginas HTML, textos, catálogo consultable, imágenes propias del
     sitio y ficheros de datos servidos desde ese dominio para su
     visualización y consulta por el navegador. No incluye el Software
     que lo genera.

1.3. "los Colaboradores": las personas voluntarias que han escrito,
     escriben o mantienen el Software, de forma desinteresada y sin
     contraprestación económica alguna a favor de la Fundación Infante
     de Orleans.

1.4. "la Fundación": la Fundación Infante de Orleans (FIO), con CIF
     [pendiente de completar], como entidad titular y beneficiaria del
     Software y del Contenido Publicado.

4.2. Se permite el acceso, la lectura, la consulta y la

       b) Uso de consulta y referencia: el Contenido Publicado solo
          podrá emplearse con fines de consulta bibliográfica,
          divulgación cultural, investigación o referencia personal —
          nunca para constituir, alimentar o complementar un catálogo,

          la Fundación o lo sustituya.
       c) Procedencia exclusiva del dominio oficial: solo se autoriza
          el uso del Contenido Publicado cuando se ha obtenido
          directamente y en el momento de la consulta desde el

          vía distinta del propio dominio — y redistribuirlo o
          publicarlo como si procediera de él.
       d) Atribución: toda redistribución permitida deberá indicar de

          medio de publicación lo permita.
