Política de privacidad

Esta web es un catálogo público de consulta, sin cuentas de usuario, sin préstamo online y sin ningún servidor propio que procese tus datos: es un conjunto de ficheros estáticos (HTML, CSS, JavaScript y un catálogo en JSON) servidos por GitHub Pages.

This website is a public read-only catalogue, with no user accounts, no online lending, and no server of our own processing your data: it's a set of static files (HTML, CSS, JavaScript and a JSON catalogue) served by GitHub Pages.

Only in your own browser (never sent to any server of ours), via localStorage:

  • El idioma que elijas (español/inglés), para no tener que volver a elegirlo en cada visita.Your chosen language (Spanish/English), so you don't have to pick it again on every visit.

Puedes borrar todo esto en cualquier momento desde los ajustes de privacidad de tu propio navegador ("borrar datos de navegación de este sitio").

You can clear all of this at any time from your own browser's privacy settings ("clear browsing data for this site").

Servicios externos que sí reciben peticionesExternal services that do receive requests

Para que la web funcione, tu navegador —directamente, sin pasar por ningún servidor nuestro— hace peticiones a los siguientes proveedores. Cada uno enlaza a su propia política de privacidad, donde encontrarás más detalle del que podemos darte aquí:

For the site to work, your browser —directly, without going through any server of ours— makes requests to the following providers. Each one links to its own privacy policy, where you'll find more detail than we can give here:

  • GitHub Pages (política de privacidadprivacy policy) — es el proveedor de hosting que sirve esta web (GitHub Pages, de GitHub/Microsoft). Al conectarte, GitHub procesa técnicamente tu petición (como haría cualquier proveedor de hosting) y puede registrar datos como tu dirección IP, el navegador que usas y la página solicitada, con fines de seguridad (por ejemplo, protección contra ataques) y de análisis de rendimiento del propio servicio de hosting. Nosotros no tenemos acceso a esos registros ni los usamos con fines distintos a mantener la web funcionando; los gestiona GitHub como responsable de ese tratamiento.is the hosting provider serving this website (GitHub Pages, run by GitHub/Microsoft). When you connect, GitHub technically processes your request (as any hosting provider would) and may log data such as your IP address, browser, and the page requested, for security purposes (e.g. protection against attacks) and to analyse the hosting service's own performance. We don't have access to those logs and don't use them for anything beyond keeping the site running; GitHub manages that processing as the responsible party.
  • jsDelivr (política de privacidadprivacy policy) — CDN usado para cargar las librerías de código Alpine.js y, si usas el escáner de etiquetas, Tesseract.js.CDN used to load the Alpine.js code library and, if you use the label scanner, Tesseract.js.
  • Google Fonts (política de privacidadprivacy policy) — para cargar la tipografía del sitio.to load the site's typeface.
  • Open Library (Internet Archive) y Google Books (política de privacidadprivacy policy) — para mostrar la portada de cada libro cuando existe (se consulta por ISBN o por título/autor). Ninguno de los dos recibe datos personales tuyos: solo el título o ISBN del libro que se está mostrando.to display each book's cover when available (looked up by ISBN or by title/author). El escáner de la cámaraThe camera scanner

Si usas la página "Escanear", la imagen de la cámara se procesa enteramente en tu propio dispositivo (nunca se sube a ningún servidor): la lectura de códigos de barras usa una función del propio navegador, y el reconocimiento de las etiquetas de referencia usa Tesseract.js, que también funciona localmente en tu navegador tras descargarse desde jsDelivr. Puedes revocar el permiso de cámara en cualquier momento desde los ajustes de tu navegador.

If you use the "Scan" page, the camera image is processed entirely on your own device (never uploaded to any server): the barcode reader uses a built-in browser function, and the reference-label recognition uses Tesseract.js, which also runs locally in your browser after being downloaded from jsDelivr. You can revoke camera permission at any time from your browser's settings.

CookiesCookies

Este sitio no usa cookies de analítica, seguimiento ni publicidad. Toda la información descrita arriba se guarda con localStorage, no con cookies.

This site doesn't use analytics, tracking or advertising cookies. All the information described above is stored with localStorage, not cookies.
